# content：網站教學內容

所有教學內容都放在這個資料夾，和網站程式分開。

| 資料夾 | 放什麼 | 分層方式 |
|---|---|---|
| `courses/` | 課程圖卡 | 學期 → 科目 |
| `homework/` | 作業（答案卷、作答頁） | 學期 → 科目 |
| `events/` | 活動 | 學期 |

## 命名規則
- 資料夾、檔名一律用**英文小寫**，單字之間用連字號 `-`，例如 `medical-biology`
- 學期資料夾：`年份_學期`，例如 `2026_y1s1`（y1＝一年級、s1＝上學期、s2＝下學期）
- **目前版本用固定檔名**（例如 `answer-sheet.html`），版本號寫在頁面內容裡；
  這樣更新版本時，舊連結不會失效
- 需要保留舊版本時，另存一份並在檔名最後加版本號，例如 `answer-sheet-v09.html`
- 不要用空格、中文、括號

## 安全
- `homework/`（作業）：**開放所有人觀看**，不用登入
- `courses/`、`events/`：**必須登入**，只限名單內的成員
- 全部都禁止搜尋引擎收錄

設定位置：`functions/_middleware.js` 的 `PUBLIC_PREFIXES`。
